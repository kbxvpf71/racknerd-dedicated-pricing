## 买之前要知道的几个坑

这一节是本文最值得看的部分，全部来自 LowEndTalk 社区的真实反馈和官方 FAQ：

1. **硬件有「抽卡」成分。** RackNerd 部分节点还在用老款 Xeon E5 v2 系列处理器，部分是较新的 Ryzen，同一价位拿到的具体型号不能自选。对性能敏感的工作负载，社区反馈一致指向独立服务器线——至少物理机的资源是独占的。下单时如果在意 CPU 型号，可以先开工单问当前库存。
2. **被 DDoS 攻击会被空路由（null-route），而且商家不会主动通知你。** 有用户服务器「失联」后才发现 IP 被空路由了几小时，RackNerd 没有开工单告知。跑容易被打的业务，要么配好监控告警，要么提前联系销售确认防护方案。
3. **拿到服务器先查 IP 信誉。** 因为大批量销售廉价机器，部分 IP 段历史记录不佳。部署后用黑名单查询工具检查一遍，发现 IP 有前科就开工单，支持通常会给换。
4. **交付需要等待。** 裸金属服务器通常 48 小时内完成部署，和 VPS 即时开通不同。项目时间敏感的话，官方建议下单前先联系确认库存和交付时间。

好消息也有：每台独立服务器都带 IPMI/KVM 访问权限，重装系统可以自己动手，不用等客服；工单响应在社区口碑里是强项，经常一小时内回复，有时几分钟，而且负责人 Dustin 会亲自出现在 LET 讨论串里回应用户问题。
